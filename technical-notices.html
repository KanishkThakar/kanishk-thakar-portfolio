Portfolio narration

Custom chapter narration and guided demo replies use the Soul Yatri — Journey Narrator instant clone, generated with ElevenLabs from the six reference recordings after the user confirmed narrator permission. The six journey questions retain the original recordings. New speech is a synthetic reproduction; an exact perceptual match is not guaranteed.

Soul Yatri Voice

The 30-second public experience is a guided browser preview using authored responses, browser speech recognition and prerecorded synthetic narration. It is not hosted inference from the local voice pipeline. The separately labelled studio sample is an original local Rumik OSS 1 output. The local pipeline combines Bodhan Indic-Transcribe Flex, Google Gemma and Rumik speech with the Kyutai Mimi codec. Model weights are not distributed.

Data boundaries
